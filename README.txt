HOW TO USE

1. Put these files in the same folder:
   index.html
   styles.css
   script.js

2. Add your own background photo as:
   background.jpg

3. Optional avatar:
   avatar.jpg

4. Edit the real conversation at the very top of script.js.

Important:
- "opening" = premade message shown first
- "expected" = accepted replies she can type
- "reply" = premade next message
- "hint" = message shown if her answer does not match

The first example is already styled after the screenshot you sent.
